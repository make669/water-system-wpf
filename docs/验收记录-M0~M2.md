## 真机冒烟发现（2026-10-11，用户问"每步都验证吗"后追加的实测）

- **现象**：真机启动后顶栏不可见——按进程矩形截图确认窗口矩形 1492×882、顶部 -83；
- **根因**：本机屏幕 1920×1080 @ **125% 缩放**，WPF 可见工作区仅 **1536×834 DIP**，
  Q1=A 的 1492×**1000** DIP 窗口纵向溢出 166 DIP；CenterScreen 居中后**标题栏（顶部 40）
  整体悬在屏幕外**——关闭按钮鼠标不可达（仅 Alt+F4）；
- **性质**：这正是概要 P17"固定尺寸小屏溢出"在用户自己的开发机上**实际发生**；
- **证据**：[m2-shell-screenshot.png](m2-shell-screenshot.png)（窗口矩形截图，顶栏缺失）；
- **处置**：提交用户重新裁决 Q1——
  - 维持 A：接受本机溢出（源项目旧裁决即如此，WinForms 版同样溢出）；
  - **改 B（推荐）**：Viewbox 矢量等比缩放，本机缩放比 ≈0.834 → 整窗 1244×834 无变形无裁切、
    标题栏可达；坐标体系零改动（Canvas 外包一层 Viewbox），实现 ≈0.5 天；
- **流程记录**：T2.4 曾在单测 13/14（单测助手自身 bug）时误合并——发现后 `git reset` 回退
  master、修正单测、重新走完整验收再合并（commit 52ab17d 内含过程记录），纪律零妥协。
